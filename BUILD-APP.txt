Station WakeUp — 公式アプリの入れ方
====================================

■ お客様向け（いちばん簡単）

1. https://station-wakeup.vercel.app/download.html を開く
2. 「公式アプリ（ZIP）をダウンロード」
3. ZIP を開き StationWakeUp-Official.apk をインストール

Android の確認画面について:
- 「有害なファイルの可能性」「保護のためブロック」は
  Playストア外アプリへの標準的な案内です
- 危険なウイルスという意味ではありません（有料ノート公式です）
- 「詳細」→「ダウンロードを続行 / それでもインストール」で進めてください
- 以前の仮版（debug）を入れている場合は、一度アンインストールしてから入れてください

■ 公式Android APK（推奨・同サイト直配信）
  ZIP（推奨・警告が出にくい）:
  https://station-wakeup.vercel.app/downloads/StationWakeUp-Official.zip
  APK（直接）:
  https://station-wakeup.vercel.app/downloads/StationWakeUp-Official.apk
  ※ 互換用: /downloads/station-wakeup.apk も同じ正式版です。
  ※ 正式版は release 署名です（debug 署名ではありません）。
  ※ ZIP → 展開 → APK の順が、Chrome の警告を避けやすいです。

■ GitHub Releases（バックアップ）
  https://github.com/nobu5129maki-crypto/station-wakeup/releases/tag/android-latest
  Assets: StationWakeUp-Official.zip / StationWakeUp-Official.apk

■ 開発者向け

リリース署名キー: android/keystore/release.jks
設定: android/keystore.properties

   npm install
   npm run android:sync
   cd android && ./gradlew assembleRelease

成果物:
  android/app/build/outputs/apk/release/app-release.apk

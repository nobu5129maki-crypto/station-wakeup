Station WakeUp — Android / iPhone で「本体バイブ」を使う手順
============================================================

ブラウザだけでは機種・OS の制限で振動が効かないことがあります。
公式アプリ（Capacitor）なら本体バイブを使えます。

■ いちばん簡単な方法（Android）

1. スマホで次を開く（GitHub経由より確実）:
   https://station-wakeup.vercel.app/download.html
   または
   https://station-wakeup.vercel.app/downloads/station-wakeup.apk
2. ダウンロード完了後、通知または「ダウンロード」フォルダから APK を開く
3. 「不明なアプリ」の許可が必要な場合あり
4. 以後はホーム画面の「Station WakeUp」アイコンから起動

※ GitHub Releases のリンクはスマホで「ダウンロードしています…」のまま
  止まることがあるため、上記のサイト直リンクを使ってください。

■ 共通（開発者向け）

   npm install
   npm run sync

■ Android（Android Studio）

   npm run android:sync
   npm run android:open

■ iPhone（Mac + Xcode）

   npm run ios:sync
   npm run ios:open

■ 画面での確認

1. バナーが「✓ 公式アプリ版で動作中」になること
2. 「② バイブレーション」が ON
3. 「バイブを試す」で振動すること
4. 監視開始で「聞き取り中（公式アプリ）」になること（マイク許可が必要）

■ メモ

- ブラウザの「ホーム画面に追加」は公式アプリではありません
- 公式 APK は downloads/station-wakeup.apk としてサイトに同梱されます
- ルートの index.html を直したら必ず npm run sync

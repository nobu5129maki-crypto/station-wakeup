Station WakeUp 公式アプリ

有料ノート購入者向けの公式アプリです。デザインは当初の画面のまま、本体バイブと駅名の聞き取りに対応しています。

安心ポイント

このファイルは Station WakeUp の公式配布です。ウイルスではありません。Playストア外のアプリでは、Android が確認画面を出すことがあります（標準の保護機能です）。

1. 公式アプリを入手

まずは ZIP（おすすめ）です。Chrome の警告が出にくい形式です。

公式アプリ（ZIP）をダウンロード APKを直接ダウンロード

2. 「有害なファイルの可能性」と出たら

Chrome が Playストア外のアプリに出す一般的な案内です。

  1. 「詳細」をタップ
  2. 「サイトを信頼してダウンロード」または「ダウンロードを続行」をタップ

3. 「デバイスを保護するためブロック」と出たら

Play プロテクトの確認画面です。危険という断定ではなく「ストア外です」という注意です。

  1. 「詳細情報」をタップ
  2. 「インストール anyway」または「それでもインストール」をタップ
  3. ホーム画面に Station WakeUp が追加されます

4. 以前の仮アプリを入れている場合

署名が新しくなったため、古い仮版が入っているときは一度削除してから入れてください。

  1. 設定 → アプリ → Station WakeUp → アンインストール
  2. このページから ZIP / APK を入れ直す

5. 使い方

  1. ホーム画面の Station WakeUp を開く
  2. 初回はマイクを「許可」
  3. 駅名を入れて「監視を開始する」

アプリ内は当初どおりのシンプルな画面です（Web向けの案内バナーは出ません）。

使い方のポイント

  • 音量を上げる＋バイブ ON で起きやすくなります。
  • 検知すると 画面点滅・音・バイブで知らせます。
  • Android / iPhone の公式アプリなら本体バイブを確実に使えます。「バイブを試す」で確認してください。
  • iPhone の Safari だけでは本体バイブ API が使えないため、確実な振動にはアプリ版を使ってください。

開き方の注意: https または localhost。スマホだけで PC の LAN アドレス（例: 192.168…）だとマイクが使えないことがあります。
